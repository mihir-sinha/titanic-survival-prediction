# Titanic Survival Prediction 

A machine learning project that predicts whether a passenger survived the Titanic disaster using Python and Scikit-learn.

##  Project Overview

The goal of this project is to build a classification model that predicts passenger survival based on information such as passenger class, sex, age, family size, fare, and port of embarkation.

##  Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib / Seaborn
- Scikit-learn
- Jupyter Notebook

##  Dataset

The dataset comes from the [Kaggle Titanic Competition](https://www.kaggle.com/competitions/titanic).

It contains passenger information used to train a model and predict survival for unseen passengers.

##  Project Workflow

1. Load and explore the dataset.
2. Handle missing values.
3. Encode categorical variables.
4. Select features for training.
5. Train a Random Forest classification model.
6. Evaluate model performance using a validation split.
7. Generate predictions for the test dataset.

##  Model and Results

- **Model:** Random Forest Classifier
- **Number of trees:** 200
- **Maximum depth:** 5
- **Validation accuracy:** 81.56%

*Note: The accuracy shown is from a local validation split, not the Kaggle competition leaderboard.*
